# 📥 Inbox

Zona di cattura rapida. Qui dentro finisce tutto ciò che non ha ancora una casa:
un'idea, un link, un appunto vocale trascritto, un risultato di test non ancora
analizzato.

Regola: **niente resta qui più di una settimana**. O diventa una nota vera in
`01-Trading/`, `02-Business/`, `03-Social/`, o si scarta.

Non serve frontmatter qui dentro — è zona di passaggio, non memoria definitiva.
